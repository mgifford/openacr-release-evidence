# Vendored ATAG 2.0 data

Source: https://github.com/w3c/wai-atag-report-tool
Ref: `main`
Commit: `40926feb7e09c7b486da4d502705cd1533fb11b2` (retrieved 2026-11-07)

`atag-2.0.json` is derived from the WAI ATAG Report Tool's `src/data/atag.js`.
It contains the ATAG 2.0 principles, guidelines and 63 success criteria used by
the WAI report tool. The `LICENSE` file is the W3C Software Notice and License.

The data is vendored only to generate a draft WAI ATAG Report Tool JSON and to
group evidence by ATAG Part A/Part B. It is not a conformance claim.
