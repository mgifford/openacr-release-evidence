# Accessibility statement for this prototype

Target: WCAG 2.2 Level AA. This is an **intent and work plan**, not a conformance
claim or a substitute for manual testing. The included UI uses semantic headings,
labels, native form controls and focus outlines; keyboard and screen reader
validation across platforms has not been completed.

Before production: test keyboard-only, NVDA/Firefox, VoiceOver/Safari, 200% and
400% zoom, forced colors/high contrast, reduced motion, dynamic updates and
error states. Record results and outstanding issues in the tracker. The UI
must not require color or charts to understand evidence statuses.

Accessibility issues should identify the tested environment and reproduction
steps and be included in the same public prioritization workflow as other bugs.
