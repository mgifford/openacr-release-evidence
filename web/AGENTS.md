# AGENTS.md: accessible static interface

- Site must render from a GitHub Pages repository subpath using relative assets.
- Use semantic HTML, native buttons/selects/details, heading order, visible
  focus, sufficient contrast, no color-only status and responsive layouts.
- Never inject issue titles, links, summaries or model text via `innerHTML` or
  other HTML sinks. Use `textContent`/`createElement` and escape in renderers.
- Do not add runtime authentication, API tokens or direct AI calls in the site.
- Display draft status, uncertainty, source dates, observation time, target
  scope/ref/installation and evidence coverage. The static report generated by
  `report.py` meets this; the legacy `web/` explorer still needs porting (see
  `AUDIT.md`).
- Any charts must have an equivalent accessible textual or tabular
  representation. The current report has no charts.
- The static report must work with JavaScript disabled and at 320 CSS px with no
  horizontal scrolling.
- Test keyboard-only (including the skip link and `<details>`), zoom, screen
  reader where possible, reduced motion, high contrast and forced-colors;
  document any gaps in `ACCESSIBILITY.md`.
- Record axe-core results separately from manual findings; automated checks do
  not establish conformance.
