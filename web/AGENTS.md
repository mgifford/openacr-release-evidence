# AGENTS.md: accessible static interface

- Site must render from a GitHub Pages repository subpath using relative assets.
- Use semantic HTML, native buttons and selects, heading order, visible focus,
  sufficient contrast, no color-only status and responsive layouts.
- Never inject issue titles, links, summaries or model text via `innerHTML`.
- Do not add runtime authentication, API tokens or direct AI calls in the site.
- Display draft, uncertainty, source dates, scope and evidence coverage.
- Any charts must have equivalent accessible textual or tabular representation.
- Test keyboard-only, zoom, screen reader where possible, reduced motion,
  high contrast and forced-colors; document any gaps in ACCESSIBILITY.md.
