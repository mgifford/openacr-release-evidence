# AGENTS.md: tests

- Fixtures are synthetic unless explicitly sourced and attributed.
- Include negative cases: closed issue not verified, future branch fix,
  missing source, conflicting evidence, unknown release, injection strings.
- Do not write tests that assert a WCAG conformance label from issue counts.
- Test output paths and relative links under GitHub Pages subpaths.
- Keep test network-free; live connector tests are separate opt-in checks.
