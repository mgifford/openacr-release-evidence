This exact release bundles 67 modules and 3 themes. The standard installation profile enables 36 modules and 1 theme; its default theme is default_admin and its admin theme is default_admin. Bundled, installed and default-installed components are different scopes. Claro left Core in 12.0.0-beta1 and is now maintained as the Claro contributed project. Its absence from this release is a scope change, not evidence that its reported barriers were fixed. Olivero left Core in 12.0.0-beta1 and is now maintained as the Olivero contributed project. Its absence from this release is a scope change, not evidence that its reported barriers were fixed. Default_admin was adopted from the Gin contributed project. Adoption does not automatically make every predecessor issue applicable; each issue needs its own release evidence.
