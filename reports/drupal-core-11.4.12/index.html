Problem/Motivation We are in the process of deprecating jQuery UI in core. jQueryUI dialog is among the components that need to be removed/replaced. Issue summary and comments (13 comments captured)

Issue summary

Problem/Motivation The language switcher block has a navigation landmark region navigation role, but the region has no accessible name. An accessible name is not strictly needed for all landmark regions. However in situations where there are multiple landmark regions of the same type on the page, the best practice is to differentiate these with an accessible name. We already do this for our menu and breadcrumb blocks. Proposed resolution Add an aria-labelledby reference to the language switcher navigation landmark region, pointing to the nested visually-hidden heading. Follow the same pattern as we already use for menu blocks. Remaining tasks patch User interface changes Adds an accessible name to the language switcher navigation landmark region, so screen reader users can differentiate it from other navigation landmarks on the page.
