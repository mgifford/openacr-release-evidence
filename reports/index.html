What this site publishes

Only reviewed, public report artifacts are deployed: the HTML report, its stylesheet, the normalized evidence JSON and the summary. Raw Drupal CLI responses, private evidence snapshots, repository files and unpublished drafts are not part of the deployed site.

The site is static and does not require JavaScript. Each report is generated by the repository pipeline and is intended for review before it informs any formal ACR.

Limitations

  • This is a draft evidence collection, not a completed ACR or a conformance claim.
  • No issue in the current report was reproduced against an installed release. Commit inclusion is not behavioural verification.
  • The sample is purposive, not a census of all Drupal accessibility issues. Absence of a reported issue is not evidence of WCAG support.
  • Raw source material is retained privately and may contain discussion not reproduced here.

Source and governance

The pipeline, evidence model and publishing rules are in the OpenACR release evidence repository. Publication follows GOVERNANCE.md; corrections and challenges are welcome through public issues.
