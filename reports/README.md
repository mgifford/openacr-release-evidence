# Generated evidence reports

`index.html` is the Pages landing page. It links to each report directory and
to the machine-readable evidence. The Pages workflow deploys this landing page
plus each report's `index.html`, `report.css`, `evidence.json` and
`summary.json`; it does not publish `collection.json`, `analysis.json` or raw
snapshots.

`drupal-core-11.4.12/` was generated by:

```sh
acr-evidence pipeline \
  --manifest config/drupal-core-11.4.12.json \
  --release 11.4.12 \
  --output reports/drupal-core-11.4.12
```

It contains normalized public evidence, the applicability analysis, and a
static, no-JavaScript HTML report. It is a **draft evidence report, not an
Accessibility Conformance Report**.

- Do not hand-edit generated files; change the manifest, source code or fixtures
  and regenerate.
- Raw CLI/API payloads are under `private-evidence/` and are not part of this
  report.
- Publication to GitHub Pages requires human approval (see `GOVERNANCE.md`).
- The `evidence.json` digest is reproducible from the published artifact; see
  `docs/EVIDENCE-MODEL.md`.
