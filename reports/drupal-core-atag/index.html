Scope and method

ATAG applies to the authoring tool interfaces used to create and edit content. This is a product-level queue inventory, not a release applicability result; issue versions and components are visible but must be verified on the target. The report is separate from the WCAG release matrix: WCAG evidence must not be inherited by ATAG, and ATAG evidence must not be treated as a WCAG result.

Limitations

  • The queue currently uses a generic atag tag. Part A/B tags were not present in the snapshot, so most issues are unspecified or only component candidates.
  • The component heuristic is editorial triage, not evidence that a criterion is met or failed.
  • No ATAG evaluation was performed against the authoring tool; no assistive-technology testing is claimed.
  • ATAG Part A/B applies to the authoring tool UI; release-specific behaviour may differ and must be reproduced on the installed version.
  • ATAG and WCAG are separate standards. This report does not modify the OpenACR WCAG draft or inherit WCAG results.
